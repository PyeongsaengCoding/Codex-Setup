# 수정·재개

남은 목표, 실패한 검사, 현재 변경 상태부터 확인한다. 이미 생성한 코드와 커밋을 보존하고 실패 근거에 맞춰 수정한다.
같은 실패가 반복되면 새 근거 없이 동일한 시도를 반복하지 말고 가설·접근을 재평가한다. 네트워크의 일시 실패와 테스트의 동작 실패를 구분한다. 외부 부작용이 있었는지 알 수 없으면 같은 작업을 무작정 재실행하지 않는다.
해결되면 같은 시나리오를 확인한다. 해결 불가이면 실패 근거·남은 상태·필요한 입력을 남긴다. 무한 재시도나 자동 모델 승격을 지침만으로 구현됐다고 주장하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
