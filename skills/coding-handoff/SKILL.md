# 인계

목표, 현재 revision, 담당 파일, 제약, 확정한 근거, 검증 결과, 남은 실패와 다음 행동을 짧게 전달한다. 전체 대화나 비밀값을 복제하지 않는다.
수신자가 읽을 파일과 필요한 범위를 지정한다. 받은 컨텍스트가 현재 코드와 충돌하면 원본을 확인한다. 전달했다는 사실을 수신자가 읽고 활용했다는 증거로 취급하지 않는다. 재개 시 작업 중 변경을 확인하고 동일 원인 조사를 근거 없이 반복하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
