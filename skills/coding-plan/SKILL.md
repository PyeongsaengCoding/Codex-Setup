# 요구사항·계획

사용자 목표를 관찰 가능한 결과로 적는다. 현재 repo 지침과 해당 코드부터 확인한다.
요구사항, 제외 범위, 영향받는 계약, 완료 조건, 검증 방법을 연결한다. 이미 답한 질문을 반복하지 않는다. 결과를 바꾸는 정보가 부족할 때만 질문하고 독립적인 조사는 계속한다.
각 요구사항에 구현 위치와 확인할 시나리오를 붙인다. 미확정 가정은 사실과 구분한다. 계획을 작성한 것을 구현 완료로 보고하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
