# 팀장과 분담

주 에이전트가 팀장이다. 먼저 적용된 공통 AGENTS가 가리키는 모델·추론 정본의 `팀장과 작업 배정`을 읽는다. 이 스킬 자체에는 모델별 추론표를 복제하지 않는다.

수락된 목표와 현재 코드를 작업 단위로 나누되 독립 실행의 이점이 있는 단위만 위임한다. 각 단위에 담당자, 분류, 명시적인 model·reasoning_effort, 읽기·쓰기 파일 범위, 선행 조건, 관련 스킬, 완료 조건, 검증 명령 또는 시나리오를 지정한다. 같은 파일에 쓰는 두 담당은 병렬 실행하지 않는다. 사용자가 모델을 지정했다면 그 지시를 적용한다.

앱 네이티브 위임 도구의 맥락 복제·모델 덮어쓰기 조건을 확인하고, 명시적 모델·추론을 적용할 수 있는 모드로 실제 배정한다. 짧은 맥락이나 독립 맥락을 넘길 때 필요한 목표·경로·제약·검증은 지시문에 포함한다. 반환된 담당 ID를 확인한다. 준비한 지시문은 실행 증거가 아니다. 담당 결과와 변경 파일을 회수하고, 필요한 검증·독립 리뷰를 통합된 코드에서 다시 확인한다. 결함과 사용자 피드백은 소유 담당에게 돌려 수정하게 하되, 공유 계약이 바뀌면 영향받는 담당과 검증 범위를 갱신한다.

작업 중에는 담당별 `준비/실행 중/완료/실패/검증됨` 상태와 근거를 짧게 관리한다. 간단한 작업에서 별도 팀을 만들지 않는다. 팀장의 최종 보고에는 실제 완료한 범위와 미확인 범위를 적는다.
