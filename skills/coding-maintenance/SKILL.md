# 기록 관리

설치 상태의 경로와 config/retention.json 정책을 확인한다. 정리 후보를 먼저 계산하고 진행 중 작업, 중요 결정, 수동 보호 기록, 미해결 실패를 제외한다.
도구가 소유한 로그만 수명에 따라 삭제한다. GAM 기억은 명시된 만료일과 임시 태그가 있는 활성 기억만 보관 처리하며 영구 삭제하지 않는다. 성공한 정리의 식별자·시각·개수만 기록하고 기억 본문은 기록하지 않는다.
앱 스케줄이 설치됐다는 사실과 실제 실행은 구분한다. 실패가 있으면 후속 실행에서 확인한다. 사용자 대화와 Codex 내부 메모리는 대상이 아니다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
