# 근거 조사

결정할 질문과 필요한 최신성을 정한다. 공식 문서와 현재 설치 버전, 저장소 사용례를 먼저 확인한다.
각 결론에 출처와 적용 버전을 연결하고 사실·추론·미확인을 나눈다. 상충하는 근거를 숨기지 않는다. 연구 결과를 코드 실행 결과로 바꾸어 보고하지 않는다. 관련성이 낮은 자료를 계속 모으지 말고 결정에 필요한 근거가 모이면 마무리한다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
