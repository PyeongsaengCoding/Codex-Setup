# 작업 보고

실행 도구에서 관찰한 작업 식별자와 상태를 읽는다. 준비·진행·실패·검증·리뷰·배포를 구분하고 알려지지 않은 값은 미확인으로 남긴다.
현재 목표에 필요한 최신 변경만 요약한다. 모델·추론은 실제 요청 설정과 관측 가능한 실행값을 구분한다. 시간·토큰은 도구가 제공할 때만 보고한다. 사용자가 볼 필요 없는 로그와 내부 상태 용어를 답변에 나열하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
