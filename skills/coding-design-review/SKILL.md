# 설계 검토

제안과 요구사항을 읽고 깨뜨릴 수 있는 구체적 반례를 찾는다. 정상 경로뿐 아니라 동시성, 권한, 실패 복구, 데이터 수명, 마이그레이션 경계를 검토한다.
대안은 동일한 요구사항과 운영 조건으로 비교한다. 독립 검토자가 실제로 참여한 경우에만 독립 검토라고 기록한다. 합의 여부와 남은 쟁점, 선택을 바꿀 근거를 반환한다. 추상적 위험 목록을 실제 결함처럼 보고하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
