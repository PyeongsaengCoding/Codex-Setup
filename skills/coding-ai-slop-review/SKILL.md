# 제품 문구

문구의 생성 위치와 표시 조건, 사용자 행동에 필요한 정보를 추적한다. 중복, 행동 없는 안내, 내부 구현 노출, 의미 없는 확인을 후보로 정리한다.
오류 설명·법적 고지·되돌릴 수 없는 행동 확인은 목적과 제품 계약을 확인한 후 판단한다. 말투 취향만으로 삭제하지 않는다. 조사 요청은 파일·조건·이유·제안으로 끝내고, 수정 요청은 실제 표시와 흐름까지 확인한다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
