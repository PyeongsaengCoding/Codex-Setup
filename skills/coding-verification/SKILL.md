# 완료 검증

현재 변경과 요구사항에 맞는 최소 충분 검사를 고른다. 각 검사에 대상 revision, 시나리오, 기대 결과, 실행 명령 또는 도구, 관찰 결과를 연결한다.
계획한 검사와 실제 통과한 검사를 분리한다. 실패는 수정 후 관련 검사를 재실행한다. 코드가 바뀌면 영향받는 증거를 갱신한다. 개별 담당 테스트 통과를 합쳐진 코드의 통합 통과로 확대하지 않는다.
코드, 로컬 테스트, 실제 화면, 외부 계정, 배포를 구분해 보고한다. 미실행·오래된 증거로 완료나 배포 성공을 주장하지 않는다.

모델·추론 선택은 적용된 공통 AGENTS가 가리키는 모델·추론 정본을 따른다. 이 스킬은 실행 모델을 변경하지 않는다.
